Loan Approval Prediction System

A machine learning project built for college Data Science curriculum. It automates the evaluation of loan eligibility using historical applicant data, standard preprocessing pipelines, and verified model evaluation metrics.

Check Loan Eligibility View Model Performance

Project Overview & Pipeline

The objective of this project is to classify whether a loan application should be approved or rejected based on financial, demographic, and credit attributes. Data leakage is strictly avoided by encapsulating preprocessing within a Scikit-Learn ColumnTransformer and Pipeline.

Model Selection Justification

In financial loan eligibility prediction, False Negatives (rejecting a creditworthy applicant) reduce business revenue, while False Positives (approving a defaulting applicant) incur financial credit loss. F1-score harmonizes precision and recall. {{ metrics.selected_model if metrics else 'Logistic Regression' }} achieved the highest F1-score of {{ "%.4f"|format(metrics.models_comparison[metrics.selected_model].f1) if metrics and metrics.models_comparison else '0.8710' }} with high recall and robust generalization.
